# ztomer Homebrew Tap

A personal Homebrew tap for macOS applications and CLI tools, custom-packaged for a seamless installation experience.

## How to Tap

To add this tap to your local Homebrew installation, run:

```bash
brew tap ztomer/tap
```

---

## Supported Casks & Formulae

| Cask / Formula | Description | Release Source | Install Command |
| :--- | :--- | :--- | :--- |
| **multitop** | Multi-server TUI dashboard — SSH into servers, watch system stats side by side | [ztomer/multitop Releases](https://github.com/ztomer/multitop/releases) | `brew install ztomer/tap/multitop` |
| **Divoom Control** | Control center for Divoom pixel displays (Pixoo/Tivoo/Ditoo/Timoo) over BLE + LAN | [ztomer/divoom_lib Releases](https://github.com/ztomer/divoom_lib/releases) | `brew install --cask ztomer/tap/divoom-control` |
| **CadGoose** | Agentic overlay companion (Desktop Goose clone with multi-goose, custom behaviors, AI chat, etc.) | [ztomer/CadGoose Releases](https://github.com/ztomer/CadGoose/releases) | `brew install --cask ztomer/tap/cadgoose` |
| **Meetspace** | Local-first meeting assistant with AI transcription and diarization analytics | [ztomer/meetspace Releases](https://github.com/ztomer/meetspace/releases) | `brew install --cask ztomer/tap/meetspace` |
| **ZTools** | Local-LLM CLI suite: weekend planner, twitter summarizer, model evaluator, image renamer. **Requires the [`osaurus`](https://osaurus.ai/) server** (`brew install --cask osaurus`) | [ztomer/ztools Releases](https://github.com/ztomer/ztools/releases) | `brew install ztomer/tap/ztools` |
